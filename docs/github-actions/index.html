No computer needed: make Claude's 5-hour window reset at your busiest hour

Every day at set times, GitHub sends a tiny "hi" from your own Claude account, so the 5-hour window resets right at your peak. Nothing has to stay on, and it's free. Pick your times below and you get the file and direct links you need.

You paste two commands into a terminal once (step 3). After that there is nothing to do. It takes about 10 minutes.

1. Pick when you want the reset

Time zone: · A day has 24 hours and a window lasts 5, so four chained windows leave 4 hours over. You choose where those 4 hours go; while you sleep is usually best.

Good to know

    
How do I change the peak later?
Pick again on this page, click "Copy file", and replace the whole file in your repository's warmup file editor, then commit.

    
Will it reset exactly at the peak?
GitHub's scheduled runs can start a few minutes late, sometimes 15+ minutes at busy times. Runs are scheduled 3 minutes early, but the reset can still slip by that much. For minute-level accuracy, claude-warmup on your own computer is more precise.

    
The peak keeps drifting
If you use Claude (on any device) in the 5 hours before the gap ends, your message opens the window first and that day's reset moves. Avoid Claude in that stretch; if it drifts, it lines up again the next day.

    
Does it cost anything? How much usage?
Private repositories get 2,000 free GitHub Actions minutes a month; this is 4 runs a day × about a minute, roughly 120 minutes a month. On Claude's side it's one short haiku hello per window, so the effect on your usage is tiny.

    
Is the token safe?
It's stored only as a secret in your private repository, and GitHub masks it in logs. This page sends nothing anywhere (your username is used in your browser only, to build links). It is still a token living outside your computer; if you'd rather not, use the local version.

    
What when the token expires?
After about a year runs fail with a red ✗. Make a new token (step 3) and replace the secret with the same name (step 4).

    
How do I stop it?
Disable the workflow in the repository's Actions tab, or delete the repository.

    
Is this allowed?
It uses Claude Code's official setup-token (made for automation) so a job in your own repository sends a tiny request from your own account. No one else's account is involved or shared. Read Anthropic's terms and decide for yourself.
