컴퓨터 없이, Claude 5시간 창을 가장 바쁜 시각에 맞추기

GitHub가 매일 정해진 시각에 내 Claude 계정으로 아주 짧은 인사("hi")를 보내 줘요. 그래서 5시간 창이 내가 가장 바쁜 시각에 딱 리셋돼요. 컴퓨터를 켜 둘 필요가 없고, 무료예요. 아래에서 시각만 고르면 필요한 파일과 바로 가는 링크를 만들어 드려요.

처음 한 번만 터미널에 명령 두 줄을 붙여 넣어야 해요(3단계). 그다음부터는 손댈 게 없어요. 다 하는 데 10분쯤 걸려요.

  3. Claude 토큰 만들기 (처음 한 번)

    3. 터미널을 닫았다가 다시 열고, 아래 줄을 붙여 넣고 Enter:

알아 둘 점

    
설정(피크 시각)을 바꾸려면?
이 페이지에서 다시 고른 뒤 "파일 내용 복사"를 누르고, 저장소의 워밍업 파일 편집 화면에서 내용을 통째로 바꿔 Commit 해요.

    
정확히 피크에 리셋되나요?
GitHub 예약 실행은 몇 분, 붐비는 시간엔 15분 넘게 늦을 때가 있어요. 그래서 3분 일찍 예약하지만, 리셋도 그만큼 밀릴 수 있어요. 분 단위로 정확해야 하면 내 컴퓨터용 claude-warmup이 더 정확해요.

    
피크가 자꾸 어긋나요
빈 시간이 끝나기 전 5시간 동안 Claude를 쓰면(다른 기기 포함) 그때 창이 먼저 열려서 그날 리셋이 밀려요. 그 시간대에는 Claude를 쓰지 않는 게 좋아요. 어긋나도 다음 날 저절로 다시 맞춰져요.

    
돈이 드나요? 사용량은요?
비공개 저장소는 GitHub Actions를 한 달 2,000분까지 무료로 쓸 수 있고, 이 워밍업은 하루 4번 × 약 1분이라 한 달 120분쯤이에요. Claude 쪽은 창마다 haiku 짧은 인사 하나라 사용량에 주는 영향은 아주 작아요.

    
토큰은 안전한가요?
토큰은 내 비공개 저장소의 비밀값에만 저장되고, GitHub는 실행 기록에도 가려서 보여 줘요. 이 페이지는 아무것도 서버로 보내지 않아요(GitHub 아이디는 링크를 만드는 데만, 내 브라우저 안에서 써요). 그래도 토큰을 내 컴퓨터 밖에 두는 건 사실이라, 그게 싫으면 내 컴퓨터용을 쓰세요.

    
토큰이 만료되면?
약 1년 뒤 실행이 빨간 ✗로 실패해요. 3단계로 새 토큰을 만들어 4단계 화면에서 같은 이름으로 바꿔 넣으면 돼요.

    
그만 쓰려면?
저장소의 Actions 탭에서 워크플로를 Disable 하거나 저장소를 지우면 멈춰요.

    
써도 괜찮은 건가요?
공식 Claude Code의 setup-token(자동화용으로 제공되는 기능)으로 내 계정에서 내 저장소의 작업이 아주 작은 요청을 보내는 거예요. 다른 사람의 계정을 맡거나 공유하지 않아요. Anthropic 약관을 읽고 직접 판단해 주세요.
