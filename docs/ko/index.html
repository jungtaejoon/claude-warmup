출근 전에 Claude 5시간 사용량 창을 미리 열어 두세요

Claude Pro·Max 한도는 첫 메시지 후 5시간이 지나야 리셋됩니다. claude-warmup은 일을 시작하기 전에 아주 짧은 메시지 하나를 보내서, 리셋이 하루 끝이 아니라 한창 일하는 중간에 오도록 맞춰 줍니다. 세션·주간 사용량도 한눈에 보여 줘요.

왜 Claude 5시간 창을 미리 열어야 하나요?

Claude 세션 한도는 첫 메시지를 보낸 순간부터 5시간 단위로 계산됩니다. 9시에 시작해서 12시에 한도에 걸리면 14시까지 기다려야 하죠. 6시에 창을 미리 열어 두면 11시에 새 창이 열립니다.

워밍업 없이
9:00 → 14:00
14:00 → 19:00

창 하나가 하루 대부분을 차지해요. 12시에 한도에 걸리면 14시까지 막힙니다.

오전 작업으로 첫 창을 다 쓸 즈음인 11시에 새 창이 열려요.

한도가 늘어나는 건 아니에요. 리셋 시점을 쓸모 있는 곳으로 옮길 뿐입니다.

동작 방식

  1. OS 스케줄러(launchd, systemd·cron, 작업 스케줄러)가 5분마다 확인을 실행합니다.
  2. 지금 창이 아직 진행 중이면 아무것도 하지 않아요. Claude를 아예 부르지 않습니다.
  3. 그렇지 않으면 Claude Code의 로컬 /usage 명령으로 사용량을 확인해요. 토큰 0, 비용 $0입니다.
  4. 열린 창이 없을 때만 공식 claude CLI로 haiku에 hi를 보냅니다. 도구·MCP·훅은 모두 끕니다.
  5. 새 창이 끝나는 시각을 기록하고 그때까지 쉽니다. "5시간마다"는 시계가 아니라 실제 창 기준이에요.

로그인 정보를 읽지 않아요

로그인은 공식 Claude Code CLI가 맡아요. API 키 변수는 지워서 API 요금이 나가지 않습니다.

의존성 0개

Node.js 18+만 있으면 되고, 한 번에 다 읽을 수 있을 만큼 작아요. MIT 라이선스.

작업 시간 지정

06:00-23:00, 평일만 등 원하는 시간과 요일에만 핑을 보내요.

설치

Node.js 18 이상과, Pro·Max 구독 계정으로 로그인한 Claude Code CLI가 필요합니다.

npm install -g github:jungtaejoon/claude-warmup
claude-warmup install

추천: 9시에 일을 시작한다면 6시부터 핑을 보내게 하세요.

claude-warmup config hours 06:00-23:00

무료 서버에서 돌리기

컴퓨터를 하루 종일 켜 둘 수 없다면, Oracle Cloud Always Free 같은 무료 클라우드 서버나 라즈베리 파이처럼 늘 켜져 있는 Linux 기기에 설치하세요. 사용량 창은 계정 단위라 어느 기기에서 핑을 보내도 됩니다.

curl -fsSLO https://raw.githubusercontent.com/jungtaejoon/claude-warmup/main/scripts/server-setup.sh && bash server-setup.sh --timezone Asia/Seoul --lang ko

Node.js, Claude Code, claude-warmup을 ~/.local에 설치하고, 브라우저 없는 로그인을 안내한 뒤 systemd 타이머를 켜 줍니다. 서버 설치 안내

자주 묻는 질문

Claude 5시간 사용량 한도는 언제 리셋되나요?

창의 첫 메시지로부터 5시간 뒤예요. 9시에 첫 메시지를 보내면 14시에 리셋되고, 6시에 워밍업하면 11시로 당겨집니다.

사용량이 늘어나나요?

아니요. 같은 한도를 작업 시간에 더 잘 맞게 배치할 뿐이에요.

워밍업은 사용량을 얼마나 쓰나요?

거의 안 써요. 확인은 로컬 /usage 명령(토큰 0)이고, 핑은 창마다 haiku 짧은 메시지 하나예요.

컴퓨터를 꺼 둬도 되나요?

네, 서버에서 돌리면 됩니다. 무료 서버에서 돌리기를 보세요.

Claude 비밀번호나 토큰을 읽나요?

아니요. 로그인은 전부 공식 claude CLI가 처리해요.

써도 괜찮은 건가요?

공식 Claude Code CLI로 내 계정에서 아주 작은 요청을 보내는 것입니다. Anthropic 약관을 읽고 직접 판단해 주세요.
