Claude 사용량 한도는 언제 리셋될까?

가이드 · Claude Pro·Max · 2026년 11월 기준

Claude Pro나 Max를 하루 종일 쓰다 보면, 한창 일하는 중에 "한도 도달, 14:00에 리셋" 같은 메시지를 보게 됩니다. 이 글에서는 리셋 시각이 어떻게 정해지는지, 내 리셋 시각은 어디서 보는지, 그리고 5시간을 꽉 채워 기다리지 않는 방법을 정리했어요.

짧은 답: 세션 한도는 창의 첫 메시지로부터 5시간 뒤에 리셋됩니다. 그 첫 메시지가 내가 9시에 보낸 것이면 14시에, 6시부터 이미 창이 흐르고 있었다면 11시에 리셋돼요.

5시간 창은 이렇게 돌아가요

  • 앞 창이 끝난 뒤 처음 보내는 메시지에서 새 창이 시작됩니다. 정해진 시계 시각에 시작하는 게 아니에요. (Claude 공식 도움말)
  • 그 창 안에서 하는 모든 사용이 한 한도로 묶여요. 웹, 데스크톱·모바일 앱, Claude Code가 한도를 같이 씁니다.
  • 창이 끝나면 세션 한도가 완전히 리셋되고, 다음 메시지가 새 창을 엽니다.
  • 이와 별도로 주간 한도도 있어요. 5시간 창을 옮겨도 주간 한도는 그대로예요.

내 리셋 시각 확인하는 법

  • Claude Code: /usage를 입력하면 현재 세션과 주간 사용량, 각각의 리셋 시각이 나와요.
  • claude.ai: 설정에서 사용량 항목을 열어 보세요.
  • claude-warmup: 터미널에서 claude-warmup을 실행하면 같은 정보를 막대그래프와 "11:00 리셋 (2시간 17분 후)" 형태로 보여 줘요.

내 첫 메시지가 손해인 이유

자리에 앉았을 때 열린 창이 없으면, 내 첫 메시지가 5시간 시계를 새로 시작해요. 일찍 한도에 걸리면 5시간 가까이를 통째로 기다려야 하죠. 아침, 점심 뒤, 저녁처럼 앞 창보다 오래 쉬었다 돌아올 때마다 이런 일이 생겨요.

창을 늘 켜 두는 법

앞 창이 끝나는 순간 새 창이 시작되게 하면, 내가 앉을 때는 언제나 이미 창이 흐르고 있어요. 5시간 중 일부가 벌써 지났으니 다음 리셋도 그만큼 가까워요. 6시부터 창을 이어 두면:

  • 창이 6:00~11:00, 11:00~16:00, 16:00~21:00로 끊김 없이 이어져요.
  • 9시에 시작하면 다음 리셋은 14시가 아니라 11시예요.
  • 점심 먹고 13시에 시작하면 18시가 아니라 16시예요.

평균적으로 다음 리셋까지 5시간이 아니라 2시간 반 정도만 남아 있어요.

방법은 세 가지예요.

  1. 직접 보내기. 창이 끝날 때마다 짧은 메시지를 보내요. 공짜지만 하루 종일 챙기기는 어려워요.
  2. 정해진 시각에 도는 작업. 정해진 시각마다 claude -p hi --model haiku를 실행하는 cron을 걸어요. 그런데 실제 창은 내가 처음 입력한 때부터 시작돼서 정해진 시각과 어긋나요. 창이 열려 있는데 보내거나, 창 사이에 빈틈이 생겨요. 클라우드 러너를 쓰면 토큰을 그쪽 시크릿에 복사해야 하는 것도 문제예요.
  3. claude-warmup 쓰기. 5분마다 로컬 /usage 명령(토큰 0)으로 확인하고, 열린 창이 없을 때만 haiku에 아주 짧은 메시지를 보내요. 그래서 앞 창이 끝나면 바로 새 창이 시작돼요. 내 컴퓨터나 서버에서 돌고, 로그인 정보는 읽지 않아요.

claude-warmup으로 설정하기

Node.js 18+와 Claude Code CLI가 필요하고, Pro나 Max로 로그인돼 있어야 해요.

npm install -g github:jungtaejoon/claude-warmup
claude-warmup install
claude-warmup config hours 06:00-23:00

마지막 명령은 창을 켜 둘 시간대를 정해요. 컴퓨터를 하루 종일 켜 둘 수 없다면, 늘 켜져 있는 무료 서버에서 돌리세요. 서버 설치 방법을 참고하세요.

알아 둘 점

  • 사용량이 늘어나는 건 아니에요. 리셋 시점만 바뀝니다.
  • 워밍업 메시지도 새 창의 아주 작은 양을 씁니다.
  • 주간 한도는 그대로 적용돼요.
