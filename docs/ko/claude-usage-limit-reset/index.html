Claude 사용량 한도는 언제 리셋될까?

가이드 · Claude Pro·Max · 2026년 11월 기준

Claude Pro나 Max를 하루 종일 쓰다 보면, 한창 일하는 중에 "한도 도달, 14:00에 리셋" 같은 메시지를 보게 됩니다. 이 글에서는 리셋 시각이 어떻게 정해지는지, 내 리셋 시각은 어디서 보는지, 그리고 리셋을 더 좋은 때로 옮기는 방법을 정리했어요.

짧은 답: 세션 한도는 창의 첫 메시지로부터 5시간 뒤에 리셋됩니다. 9시에 첫 메시지를 보내면 14시에, 6시에 보내면 11시에 리셋돼요.

5시간 창은 이렇게 돌아가요

  • 앞 창이 끝난 뒤 처음 보내는 메시지에서 새 창이 시작됩니다. 정해진 시계 시각에 시작하는 게 아니에요. (Claude 공식 도움말)
  • 그 창 안에서 하는 모든 사용이 한 한도로 묶여요. 웹, 데스크톱·모바일 앱, Claude Code가 한도를 같이 씁니다.
  • 창이 끝나면 세션 한도가 완전히 리셋되고, 다음 메시지가 새 창을 엽니다.
  • 이와 별도로 주간 한도도 있어요. 5시간 창을 옮겨도 주간 한도는 그대로예요.

내 리셋 시각 확인하는 법

  • Claude Code: /usage를 입력하면 현재 세션과 주간 사용량, 각각의 리셋 시각이 나와요.
  • claude.ai: 설정에서 사용량 항목을 열어 보세요.
  • claude-warmup: 터미널에서 claude-warmup을 실행하면 같은 정보를 막대그래프와 "11:00 리셋 (2시간 17분 후)" 형태로 보여 줘요.

기본 타이밍이 손해인 이유

대부분 일을 시작할 때 첫 메시지를 보내요. 그러면 오전 전체가 한 창에 들어가고, 바쁜 오전이면 정오쯤 한도를 다 써 버려요. 리셋은 오후 2시쯤에야 와서, 가장 집중이 잘 되는 시간에 기다리게 됩니다.

리셋이 일하는 중간에 오게 하는 법

일을 시작하기 전에 창을 열어 두면 돼요. 9시에 일을 시작한다면 6시쯤 창을 엽니다.

  • 6:00~11:00: 첫 번째 창. 실제로는 9시~11시만 써요.
  • 11:00: 오전 작업으로 한도에 걸릴 무렵 새 창이 열려요.
  • 16:00: 늦은 오후를 위한 또 하나의 새 창.

방법은 세 가지예요.

  1. 직접 보내기. 일어나서 휴대폰으로 아무 짧은 메시지나 보내요. 공짜고 간단하지만 잊기 쉬워요.
  2. 정해진 시각에 도는 작업. 6시에 claude -p hi --model haiku를 실행하는 cron을 걸어요. 되긴 하지만, 창이 이미 열려 있어도 정해진 시각에 보내고, 클라우드 러너를 쓰면 토큰을 그쪽 시크릿에 복사해야 해요.
  3. claude-warmup 쓰기. 5분마다 로컬 /usage 명령(토큰 0)으로 확인하고, 열린 창이 없을 때만 haiku에 아주 짧은 메시지를 보내요. 내 컴퓨터나 서버에서 돌고, 로그인 정보는 읽지 않아요.

claude-warmup으로 설정하기

Node.js 18+와 Claude Code CLI가 필요하고, Pro나 Max로 로그인돼 있어야 해요.

npm install -g github:jungtaejoon/claude-warmup
claude-warmup install
claude-warmup config hours 06:00-23:00

새벽에 컴퓨터가 꺼져 있다면, 늘 켜져 있는 무료 서버에서 돌리세요. 서버 설치 방법을 참고하세요.

알아 둘 점

  • 사용량이 늘어나는 건 아니에요. 리셋 시점만 바뀝니다.
  • 워밍업 메시지도 새 창의 아주 작은 양을 씁니다.
  • 주간 한도는 그대로 적용돼요.
